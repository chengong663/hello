# 05 · 范文拆解：实测稿

`samples/excel-measure/body.html` 是可直接复制改写的实测稿模板。
下面拆解它为什么这么写，以及哪些地方可以直接套。

---

## 一、全文骨架

| 位置 | 组件 | 作用 |
|---|---|---|
| 开头 | 灰底蓝边「实测卡片」 | 4 行交代清楚：做了什么、原来多久、现在多久、代价是什么 |
| 承接 | 三段短句（2天 → 烦在哪 → 换做法） | 制造落差 |
| 高光 | 19px 加粗单句「结果花了 40 分钟。」 | 全篇第一个重音 |
| 论据 | 流程对比图 + 图注 | 唯一一张图，承担核心论据 |
| 第 1 段 | 脏数据的具体形态 | 建立真实感（三种日期格式） |
| 第 2 段 | 我的操作顺序（脱敏 → 提示词 → 报错 → 跑通） | 可复制性 |
| 第 3 段 | 三个坑 | 全文最值钱，决定收藏率 |
| 第 4 段 | 完整提示词 + 一句关键说明 | 转发理由 |
| 收尾 | 「说点实话」+ 70/30 判断 | 拆掉神话，立人设 |
| 钩子 | 蓝底关键词回复 | 唯一转化位 |
| 免责 | 灰色小字 | 降低被杠风险 |

---

## 二、五个可直接套用的写法

### 1. 开头不要导语，要卡片

```html
<p style="background:#f5f5f7;border-left:4px solid #0a84ff;padding:18px 22px;margin:0 0 34px;font-size:15px;line-height:1.75;color:#333;border-radius:0 6px 6px 0;">
<strong style="color:#0a84ff;">实测记录</strong><br/>
做的事：……<br/>
原来：约 X 天　　现在：Y 分钟<br/>
代价：……
</p>
```

「代价」这一行是可信度来源。只报省了多少时间，读者会怀疑；主动说出返工和试错，反而信。

### 2. 细节要具体到能被验证

- ❌「日期格式不统一」
- ✅「A 店是 2026/11/1，B 店是 2026-11-01，C 店写成 11 月 1 日」

读者能想象出那张表，才会信你真实操过。

### 3. 一个章节一个判断，判断单独成段

第 1 段结尾：

```html
<p style="font-size:17px;font-weight:bold;color:#e53935;margin:0 0 34px;line-height:1.85;">
做表最耗时间的从来不是算数，是把脏数据洗干净。
</p>
```

17px 加粗变色 + 前后大间距。**每段最多一句这样的句子**，多了就失效。

### 4. 坑的部分用「加粗小标题 + 独立段落」

```html
<p><strong>坑一，合并单元格必炸。</strong></p>
<p>只要表里有合并单元格，读进来的数据就会错位。跑之前先全部拆开，把空白补齐。</p>
```

一句标题，一句解释，各占一段。信息密度高且好扫读。

### 5. 收尾必须拆神话

```
它替我做的是我不想做的那 70%。
剩下的 30%，才是我的活。
```

这句是全文的「人设锚点」。所有「AI 一夜替我干完活」的说法都不要写，
写出边界反而显得专业，也是这个号后续能持续写下去的前提。

## 三、样式参数（照着改就行）

| 用途 | 参数 |
|---|---|
| 正文 | `font-size:15px;color:#333;line-height:1.9;margin:0 0 16px` |
| 章节序号徽标 | 19px 白字 + `#0a84ff` 底 + 圆角 8px |
| 章节标题 | `font-size:20px;font-weight:bold;color:#0a84ff` + 底部 3px 同色下划线 |
| 金句 | `font-size:17px;font-weight:bold` 换色，前后 margin 34px |
| 代码/提示词块 | `#f7f9fc` 底 + `#e3e9f0` 边 + 圆角 8px |
| 警告引用 | `#fdf3f3` 底 + 左侧 4px `#e53935` |
| 钩子 | `#f0f6ff` 底 + 圆角 8px + 深蓝字 |

---

## 四、改写检查

拿这份模板改写新选题时，确认：

- [ ] 卡片里的四个数字都换成了自己的真实数据
- [ ] 第 1 段有三个以上的具体细节（真实文件长什么样）
- [ ] 第 2 段写了至少一次失败
- [ ] 第 3 段三个坑是自己的，不是搜来的通用坑
- [ ] 提示词是真正跑通的那版，不是编的
- [ ] 结尾有边界判断，没有「AI 全自动」
- [ ] 钩子送的东西真的存在，能立刻发出去

最后一条最容易被忽略：**承诺的模板必须随发随给**，否则第一次就失信。
