# 03 · 写作

## 一、去 AI 味五条（默认执行）

1. **一到两句一段**。想到一句发一句，严禁三四句焊成一坨。
2. **杀掉缝合语**。「与此同时」「值得注意的是」「综上所述」「接下来我们看」全部删掉，段落直接跳。
3. **事实密度优先**。具体数字、具体机制、具体细节，比十句形容词有用。
4. **允许不完整**。半截句、省略主语、没有中心句的段落，真人都这么写。
5. **观点少而准，尽量后置**。不要段段下判断，事实铺够了，一句就够。

## 二、作者必须在场（但别表演）

- ✅ 在场且真诚：「上个月我对着三张表坐了两天。」
- ❌ 表演式：「我删掉了写了两天的稿子！你敢信？」
- ❌ 隐身式：通篇客观陈述，读完不知道谁在说话

个人号默认第一人称。情绪用低强度着色（「挺有意思」「有点反常」），不用「太炸裂了」。

## 三、三种主力结构

### A. 实测稿（最推荐新号）

```
实测卡片    时间 / 任务 / 原耗时 / 现耗时 / 代价
一张对比图  流程前后对比
1 问题有多烦  三个具体细节，建立真实感
2 我怎么做的  步骤 + 返工 + 提示词
3 踩了几个坑  全文最值钱的部分
4 可复制的模板 直接能抄的东西
收尾        拆掉神话，给一个真实判断
钩子        关键词回复领模板
```

### B. 观点稿

```
一个具体切口（不是导语）
反常的事实或数据
我的判断
三条论据
反方最强的说法是什么，我怎么回应
回到开头那个切口
```

### C. 清单稿

```
一句话说清这份清单解决什么问题
每条：是什么 → 为什么 → 怎么做
每条控制在一屏内
结尾说明使用顺序
```

## 四、强调规则（硬底线）

每篇必须有 3–5 处正文强调，通篇平铺等于没写。

可用手段：

- `<strong>` 加粗
- 变色加粗（最重的一两句）
- 单句成段（居中放大，靠留白做重音）
- 引用块（金句、原话、警告）

**要挑出来的句子**：能被截图转发的、反直觉的、承担全篇重量的。

但不要过度：同一屏别堆三四处，别给普通陈述句上色。

## 五、图文底线

每篇至少一张**承载论据**的图：

- 数据图（matplotlib / 手绘 SVG）
- 流程图 / 时间线 / 结构图
- 真实截图（实测稿必须自己截，不能用网图）

判断标准：把图拿掉，读者还能读懂吗？能读懂就是废图。

## 六、排版参数

| 项目 | 参数 |
|---|---|
| 正文字号 | 15–16px |
| 行距 | 1.8–1.9 |
| 段距 | 单空行 |
| 首行缩进 | 不缩进 |
| 对齐 | 左对齐 |

## 七、成稿自检

- [ ] 开头三行能不能让人知道这篇讲什么
- [ ] 有没有超过 4 句的段落
- [ ] 有没有缝合语
- [ ] 有没有 3 处以上强调
- [ ] 有没有一张真正有用的图
- [ ] 结尾有没有钩子
- [ ] 念出声，像不像人话
