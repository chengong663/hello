## 一、核心冲突源

修仙世界的"天劫"被房地产资本改造了——飞升=还完房贷，渡劫=月供逾期。穿越者被系统强制绑定前世房贷，成为仙界银行的"优质客户"（收割对象）。

**一句话概括**：穿越修仙界，房贷跟着过来了。修为越高，月供越贵。

## 二、物理规则层

### 2.1 灵气与货币体系
| 单位 | 等价关系 | 说明 |
|---|---|---|
| 灵气点数 | 基础单位 | 修仙界通用能源/货币 |
| 灵石 | 1块 = 10点灵气 | 实体货币，可交易可存 |
| 人民币 | 内部汇率 1:200-1:300 | 黑市抽七成，正规渠道抽三成 |
| 月供点数 | 随境界浮动 | 境界越高，月供越贵 |

### 2.2 境界与贷款额度映射
| 境界 | 月供点数 | 贷款期限 | 备注 |
|---|---|---|---|
| 练气期（首付） | 0-500 | 首付阶段 | 穿越者起始境界 |
| 筑基期 | 3,270 | 300年 | 主线起始状态 |
| 金丹期 | 8,910 | 200年 | 月供涨幅 2.7x |
| 元婴期 | 27,300 | 100年 | 月供涨幅 3.1x |
| 化神期 | 81,900 | 50年 | 月供涨幅 3x |
| 飞升 | 全额还清 | 无期限 | 付清本金+利息+保险金 |

**规则**：每突破一个大境界，仙界银行自动上调月供——贷款合同绑定修为等级。

### 2.3 逾期机制（核心约束）
| 逾期天数 | 后果 | 可恢复 |
|---|---|---|
| 0-3天 | 正常计息（每天3点逾期费） | ✓ 随时补还 |
| 3-10天 | 经脉轻度冻结（打坐效率-30%） | ✓ 补还后3天恢复 |
| 10-30天 | 经脉中度冻结（打坐效率-70%）+ 拆迁队预警 | △ 需要额外缴纳滞纳金 |
| 30-90天 | 经脉重度冻结（打坐效率为0）+ 拆迁队待命 | ✗ 基本无法恢复 |
| 90-100天 | 拆迁队强拆洞府 | ✗ |
| 100+天 | 经脉反噬（血管青黑色，不可逆） | ✗ |
| 365+天 | 魂飞魄散 | ✗ |

### 2.4 灵气获取方式
| 方式 | 效率 | 风险 | 备注 |
|---|---|---|---|
| 打坐吸收天地灵气 | 10点/天（散修） | 无 | 位置好的区域翻倍 |
| 跨平台交易（现代→修仙） | 不限量 | 被仙界银行检测（利率上浮） | 主角核心手段 |
| 杀人夺宝 | 不定 | 被追杀+天道谴责 | 高风险高回报 |
| 宗门俸禄 | 100-1000点/月 | 受宗门控制 | 宗门弟子专属 |

### 2.5 灵气地雷（主角自制武器）
| 规格 | 爆炸范围 | 制作材料 | 备注 |
|---|---|---|---|
| 100点 | 碎石 | 灵气球+石头 | 实验级 |
| 500点 | 炸树 | 灵气球+石头 | 野外战斗 |

## 三、社会规则层

### 3.1 主要势力
| 势力 | 背景 | 与主角关系 | 总部 |
|---|---|---|---|
| **天衡地产** | 仙界银行母公司，控制90%修仙界房产 | 核心敌对 | 青云山·天衡城 |
| **仙界银行** | 天衡地产子公司，掌管所有修士贷款 | 直接敌对 | 青阳城分行 |
| **拆迁队** | 天衡地产下属妖兽部队 | 执行层面敌对 | 青阳城后山 |
| **散修群体** | 无门派无贷款的自由修士 | 盟友/中立 | 各城散修聚集点 |
| **各大门派** | 形式独立，实质向天衡交税 | 中立偏敌对 | 各山各峰 |
| **修仙业主联合会** | 主角创立的逾期者组织 | 己方 | 青阳城·小溪边 |

### 3.3 穿越者收割机制（核心设定）
1. 现代房贷 → 修仙房贷，自动转换（本金不变，月供按灵气点数）
2. 穿越者的前世身份/记忆保留，但银行卡被仙界银行接管
3. 穿越者起始境界 = 练气期，自动分配茅草屋（贷款抵押物）
4. 所有穿越者都带着房贷过来 —— 天衡地产是"收割机"
5. 收割原因待揭秘（可能是仙界银行需要灵气运转，穿越者的房贷是灵气来源）

## 四、约束规则层

### 4.1 绝对禁止
- ✗ 私建"违建洞府"——查到直接断供
- ✗ 绕过黑市直接交易灵气——仙界银行检测到利率上浮
- ✗ 逾期100天以上不还款——经脉反噬不可逆
- ✗ 对天衡地产高层下杀手——会招来整个拆迁队

### 4.2 汇率波动规则
- 月初 1:200（人民币→灵气）
- 月末可能跌到 1:50
- 汇率由天道波动控制，没人能完全预测

### 4.3 贷款利率
- 穿越者起始：4.2%（和穿越前一致）
- 被检测到非正规交易：立即上浮到 6.8%+
- 逾期超过10天：额外上浮 0.5%
