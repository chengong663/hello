# 大牙（B级·盟友/妖兽军团领袖）

> 五维人物卡 | Soul Field | 语言指纹 | 成长弧线

---

## 1. 基础身份

- **姓名**：大牙（本名不可考，本土妖兽，牙齿比同类长三倍）
- **年龄**：本土妖兽至少活了200年（穿越者没到之前就在灵脉里挖洞）
- **性别**：雄性
- **记忆锚点**：记得灵脉被抽之前的样子——整条山都是蓝色的，像泡在水里
- **职业**：本土妖兽族群首领（300只）+ 灵脉隧道挖掘专家
- **穿越时间**：不属于穿越者，是本土原住民
- **境界**：无修为等级（妖兽不修仙，灵气就是它的食物）

---

## 2. 核心性格

| 项目 | 内容 |
|---|---|
| **核心驱动** | 灵脉要好好的——妖兽靠灵气活着，没灵脉就是死 |
| **价值锚点** | 灵脉是根，不能让它干了 |
| **深层恐惧** | 灵脉被抽干→族群全灭→自己是最后一只 |
| **表层恐惧** | 仙界银行的"收割"——那不是抽灵气，是**抽骨头** |
| **冲突下第一反应** | 挖洞→把族群藏进去→再出来咬 |
| **底层性格** | 憨、直、不聪明但记仇、对灵脉有近乎本能的直觉 |
| **底线** | 不让族群死 |

---

## 3. Soul Field（两条铁律）

| # | 铁律 | 适用条件 |
|---|---|---|
| 1 | 灵脉在，族群在——灵脉干了，全族群一起死 | 任何重大决定 |
| 2 | 人类不害我，我不害人类——人类帮我，我帮人类 | 与穿越者的关系 |

---

## 4. 语言指纹

| 项目 | 内容 |
|---|---|
| **表达方式** | 说话带兽语的咕噜声，偶尔用爪子拍地面辅助表达 |
| **口头禅** | "挖"、"灵脉好"、"洞"、"吃" |
| **严禁说的词** | （妖兽不说人类的空话） |
| **生气时的表现** | 牙齿露出来三倍长→拍地面→附近灵脉震动（它在借灵气震人） |
| **紧张时的表现** | 往洞的方向退半步 |
| **开心时的表现** | 蹲下来啃灵石头，尾巴甩三下 |

### 对话正例
```
（爪子拍地面，震出一圈灵气涟漪）"陈默。洞。通了。"
"灵脉好。我挖。"
（对着上海方向，声音像从山洞里飘出来）"灵气。那个方向。很多。"
```

## 5. 成长弧线

| 阶段 | 状态 | 关键转折 |
|---|---|---|
| 卷一初期 | 躲在洞里，被陈默的23331频率吸引出来 | 第一次和穿越者对话——之前只见过被收割的穿越者尸体 |
| 卷一中段 | 发现灵气也是灵脉→挖灵气炸弹→炸灵气守卫 | 原来"灵气池"不是仙界银行的，是**大牙的食物** |
| 卷二 | 挖通灵脉通道→从青阳城挖到上海 | 37条灵脉全挖过，现在挖第四条异界边界 |
| 卷三 | 挖现代通道往天上挖→想"回"灵气的故乡 | 灵气融合后通道打开，但现代通道挖没挖通是开放结局 |

---

## 6. 角色弧线终局

- **状态**：继续挖，想挖回现代
- **关键选择**：帮人类→因为灵脉是共同的根
- **铁律表现**：Soul Field #1（灵脉在族群在）→卷一里妖兽集体罢工，就是因为陈默说"灵脉不会死"
- **最终平衡**：它从来不是棋子——它是灵脉的原住民，穿越者来了它才"被卷入"。它的自由从来不需要靠炸系统来获得——它的自由就是挖洞
