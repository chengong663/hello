# 王磊（A级·盟友/飞升后复活）

> 五维人物卡 | Soul Field | 语言指纹 | 成长弧线

---

## 1. 基础身份

- **姓名**：王磊
- **年龄**：穿越前35岁，穿越后约12年飞升
- **性别**：男
- **记忆锚点**：穿越前是上海某程序员，写了10年代码，还完了90万房贷（提前还的，差两万没还）；飞升那天他以为是终于"回家"了
- **职业**：穿越前=后端开发；穿越后=散修→主动还完房贷→飞升→意识被熔→逃出来→在灵脉里飘了X年→被陈默的23331共振激活
- **穿越时间**：约12年前（比陈默早11年）
- **境界**：无境界（正常人类，飞升后意识碎片重组，没有修为）

---

## 2. 核心性格

| 项目 | 内容 |
|---|---|
| **核心驱动** | 搞清楚飞升到底是什么——他还完了房贷，应该"回家"了，结果被熔了 |
| **价值锚点** | 程序员的因果逻辑：输入→处理→输出。房贷=输入→还完=处理→飞升=输出。但输出不对 |
| **深层恐惧** | 自己被熔的时候还"算"着该"回家"——怕自己不是被骗，是**主动走进陷阱** |
| **表层恐惧** | 再被熔一次——意识第二次碎了就拼不回来了 |
| **冲突下第一反应** | 写代码→或者用灵脉共振当代码执行 |
| **底层性格** | 温和、老实、有点迂腐、对因果逻辑有病态执着 |
| **底线** | 不能让其他人像他一样被骗着走进熔炉 |

---

## 3. Soul Field（两条铁律）

| # | 铁律 | 适用条件 |
|---|---|---|
| 1 | 程序有bug就要写patch，哪怕这个"程序"是仙界银行的收割系统 | 所有破局方案 |
| 2 | 还完房贷≠自由——自由是知道自己在做什么 | 对所有穿越者的态度 |

---

## 4. 语言指纹

| 项目 | 内容 |
|---|---|
| **句子形状** | 长句，带括号注释，像在写代码注释 |
| **口头禅** | "这个逻辑不对"、"有bug"、"patch可以这样写"、"输入输出要对齐" |
| **严禁说的词** | "算了"、"无所谓"（程序员的严谨） |
| **生气时的表现** | 不说话，在空气里划括号（代码的花括号） |
| **紧张时的表现** | 摸口袋——那里有一块他从飞升管道里抠出来的金属碎片（形状像一个花括号） |
| **开心时的表现** | 说"编译通过"（很少有人听懂） |

### 对话正例
```
"飞升管道是个无限循环。房贷=资源消耗→还完=触发飞升→飞升=熔成灵气→灵气=新穿越者的修炼资源。没有break条件。"
"萧云在出口留了一个return 0。但仙界银行把它改成了return 1（错误码）。我是第一个触发return 1的人。"
"那个72小时凝结公式——我写了10年的后端，那个共振曲线我见过。和TCP三次握手一样。"
```

## 5. 成长弧线

| 阶段 | 状态 | 关键转折 |
|---|---|---|
| 穿越初期 | 老老实实还房贷，以为飞升就是"还清了，回家" | 还完最后两万那天，飞升管道亮了——他走进去了 |
| 飞升时 | 意识被熔成碎片——疼，然后突然23331共振了一下（陈默在激活旧计算器），他逃出来了 | 飘在灵脉里，意识碎片重组 |
| 飘着的时候 | 看陈默穿越，看他激活23331，看他炸林七 | 有人算得比他准，用的是他当年写后端的逻辑 |
| 卷一收束 | 被陈默的灵气接力激活→意识完整重组→正常人类 | 能穿衣服，能走路，脸上有表情 |
| 卷三 | 穿T恤牛仔裤，灵脉散步，想帮苏晚看账本里有没有逻辑bug | 终于活过来了，知道自己在做什么了 |

## 6. 角色弧线终局

- **状态**：正常人类，活在青阳城，穿现代偷来的衣服
- **关键选择**：主动走进飞升管道（被骗）→逃出来（靠23331共振）→激活旧计算器（帮陈默）
- **铁律表现**：Soul Field #1（程序有bug就要写patch）→他是第一个理解"飞升管道是无限循环没有break条件"的人，也是第一个能用代码逻辑写破局方案的人
- **最终平衡**：他是陈默的"前任程序员前辈"——同样被23331绑定，同样用代码思维破局。唯一的不同是：他被熔过，所以他更怕自己再被骗
