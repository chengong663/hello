# 苏明（B级·苏晚弟/上海穿越者）

> 五维人物卡 | Soul Field | 语言指纹 | 成长弧线

---

## 1. 基础身份

- **姓名**：苏明
- **年龄**：穿越前26岁，穿越后约3个月（比苏晚晚3个月穿越）
- **性别**：男
- **记忆锚点**：穿越前是上海某互联网公司前端开发，和苏晚是姐弟，苏晚是会计；穿越后月供15600，以为还完就能回去
- **职业**：穿越前=前端开发；穿越后=散修→上海灵脉节点废弃支脉→和赵七联系
- **穿越时间**：比苏晚晚3个月（苏晚穿越后给现代写了求助信，苏明帮还房贷时穿越）
- **境界**：筑基期（刚穿越）→月供清零后在学灵气接力

## 4. 语言指纹

| 项目 | 内容 |
|---|---|
| **句子形状** | 长句，像在写前端注释，偶尔用现代互联网术语 |
| **口头禅** | "这个前端页面怎么渲染出来的"、"和姐的月供数据对不上"、"赵七说的算法我能看懂" |
| **严禁说的词** | "我不管"、"算了" |
| **生气时的表现** | 快速眨眼三次（前端debug时的习惯） |
| **紧张时的表现** | 摸口袋——那里有苏晚传信用的灵石头 |
| **开心时的表现** | 笑的时候和苏晚一样——嘴角先动左眼再动 |

### 对话正例
```
"三个月了，我第一次收到姐的回信。灵气一笔一划写的。我攒了3000点灵气传的。"
"赵七在设计干扰算法——七日七煞，和我写前端的事件循环一样。"
"月供15600。还了11个月。还差——"（停顿，算）"23万。"
```
