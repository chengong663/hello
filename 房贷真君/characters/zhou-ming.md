# 周明（A级·盟友/化神之上）

> 五维人物卡 | Soul Field | 语言指纹 | 成长弧线

---

## 1. 基础身份

- **姓名**：周明
- **年龄**：穿越前32岁，穿越后约8年
- **性别**：男
- **记忆锚点**：穿越前是特种兵，野外生存教官，执行过7次边境任务；穿越后是仙界银行灵卫总长，被萧云揭发后反水
- **职业**：穿越前=武警特战队副队长；穿越后=灵卫总长→元婴碎八成→灵脉养伤→化神之上
- **穿越时间**：约8年前
- **境界**：化神之上（=仙界银行体系外的自由灵气形态，没有名字，没有瓶颈）

---

## 2. 核心性格

| 项目 | 内容 |
|---|---|
| **核心驱动** | 活下去+不让身边的人死 |
| **价值锚点** | 兄弟是要救的，哪怕自己碎了 |
| **深层恐惧** | 自己不够强，保护不了想保护的人 |
| **表层恐惧** | 元婴碎第二次——第一次碎了八成，再碎就是意识消失 |
| **冲突下第一反应** | 先动手再想——特种兵的肌肉记忆 |
| **底层性格** | 直、硬、话少、认死理、不搞阴谋 |
| **底线** | 自己的人不能被仙界银行熔掉 |

---

## 3. Soul Field（三条铁律）

| # | 铁律 | 适用条件 |
|---|---|---|
| 1 | 兄弟倒了，我补位——哪怕我是最后一个 | 每次战斗 |
| 2 | 不打弱者——包括不打被锁链压着的人 | 选择攻击目标时 |
| 3 | 欠的用命还，不欠的不接 | 报恩时 |

## 4. 语言指纹

| 项目 | 内容 |
|---|---|
| **句子形状** | 极短句，命令式，像在下达作战指令 |
| **口头禅** | "走"、"打"、"撤"、"跟上" |
| **严禁说的词** | "我觉得"、"可能"、"等等我" |
| **生气时的表现** | 沉默→灵气波动变重→附近灵脉震动 |
| **紧张时的表现** | 握拳→指节发白→灵气自动裹住手臂 |
| **开心时的表现** | 咧嘴笑一下（全书不超过3次） |
| **信息密度** | 低——不说废话，但一开口就是结论 |

### 对话正例
```
"灵脉碎片200块。每块50万。用我的元婴当引线。"
"萧云是卧底。我不管。他给的情报是准的。"
"化神之上是什么。不知道。但舒服了。"
```

## 5. 成长弧线

| 阶段 | 状态 | 关键转折 |
|---|---|---|
| 穿越初期 | 以为是修仙世界，努力修炼到化神期，当上灵卫总长 | 陈默告诉他飞升=熔炉，他不信→看了王磊飞升的记录→反水 |
| 卷一后半 | 和陈默联手炸林七→元婴碎八成→用灵脉碎片养伤 | 从"听命令"到"自己选" |
| 卷二 | 灵脉里躺着，碎片慢慢重组，灵气浓度太高反而在涨 | 修仙体系的瓶颈在松动——因为体系本身在崩塌 |
| 卷三 | 灵脉涨8.9倍→元婴碎片重组→灵气形态从金色变透明→化神之上 | 仙界银行的修为体系=收割体系的副产品→收割终止→体系崩塌→瓶颈消失 |

---

## 6. 角色弧线终局

- **状态**：化神之上，在灵脉里散步，想试能不能挖通仙界银行留的"上面"看看
- **关键选择**：相信陈默→反水→碎了元婴→等了半年→突破天花板
- **铁律表现**：Soul Field #1（兄弟倒了我补位）→Ch40炸灵气守卫时他主动用自己元婴当引线
- **最终平衡**：没有更高境界了，但他不觉得遗憾——因为上面本来就是个不存在的东西
