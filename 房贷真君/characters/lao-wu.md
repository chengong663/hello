# 老吴（C级·铸器师/矿工/灵气匕首制造者）

> 五维人物卡 | Soul Field | 语言指纹 | 成长弧线

---

## 1. 基础身份

- **姓名**：老吴（本名吴顺，穿越前矿工出身，大家都叫他老吴）
- **年龄**：穿越前42岁，穿越后约15年
- **性别**：男
- **记忆锚点**：穿越前是山西某煤矿井下矿工，能凭敲击声判断煤层厚度；穿越后筑基期散修，挖了15年灵脉矿洞，左腿在矿洞塌方时瘸了；逾期83天→躲在废弃矿洞里→给陈默铸灵气匕首
- **职业**：穿越前=煤矿井下矿工；穿越后=灵脉矿工→铸器师→灵气匕首1000把免费送
- **穿越时间**：约15年前（最早的一批穿越者之一）
- **境界**：筑基期（战力弱，但对灵脉结构了如指掌）

---

## 2. 核心性格

| 项目 | 内容 |
|---|---|
| **核心驱动** | 躲→活→然后铸点东西帮大家 |
| **价值锚点** | 矿工的铁则：井下要互相救，不能丢下一个 |
| **深层恐惧** | 逾期100天经脉反噬→逾期200天意识消失→逾期365天魂飞魄散 |
| **表层恐惧** | 天衡地产的人跟踪了三个月——矿洞知道他在这儿，但不敢进来（有灵气陷阱） |
| **冲突下第一反应** | 躲→钻矿洞→用灵气敲岩壁发出信号 |
| **底层性格** | 沉默、踏实、手艺人、不搞阴谋、被谁帮了就给人铸匕首 |
| **底线** | 矿洞里的兄弟们不能被天衡拆了 |

---

## 3. Soul Field（两条铁律）

| # | 铁律 | 适用条件 |
|---|---|---|
| 1 | 敲三下岩壁=安全，敲两下=有人来——矿工暗号 | 矿洞里的所有行动 |
| 2 | 被谁帮了，就给人铸一把匕首——不收灵气，纯帮忙 | 所有受助后 |

## 4. 语言指纹

| 项目 | 内容 |
|---|---|
| **句子形状** | 极短句，带矿工方言，偶尔用灵气敲三下岩壁代替说话 |
| **口头禅** | "敲三下"、"矿洞"、"灵脉在下面"、"不躲会死" |
| **严禁说的词** | "漂亮话"、"应该"、"大概" |
| **生气时的表现** | 不说话→用灵气敲岩壁→三下→矿洞里的灵气陷阱自动启动 |
| **紧张时的表现** | 往矿洞深处退→左腿瘸但爬得快→摸怀里的那块灵脉石头（张三留的） |
| **开心时的表现** | 啃虫子→牙很黄但咬得整齐→灵气匕首磨得亮 |

### 对话正例
```
（啃虫子，左手攥着半只绿色虫子）"你谁？"
"张三来过。给我留了这块。说这管子通仙界银行总服务器。能倒过来用。"
（用灵气敲岩壁三下）"安全。进来吧。"
```

| 阶段 | 状态 | 关键转折 |
|---|---|---|

## 6. 角色弧线终局

- **状态**：灵脉山铸器坊，继续铸灵气匕首
- **关键选择**：躲→被陈默找→帮陈默→铸匕首
- **铁律表现**：Soul Field #2（被谁帮了铸匕首）→陈默帮他逃，他铸1000把；苏晚帮他算逾期，他铸碳笔形匕首
- **特殊能力**：
  - 二十年矿工→能凭手感计数灵脉进出场时间→代替秒表
  - 能听出灵脉"三进七停"的节奏（陈默后来自己也数出来了）
  - 矿洞里有灵气陷阱→天衡地产的人不敢进来
