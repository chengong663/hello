## 都市修真流派特殊规则

| 规则 | 说明 |
|---|---|
| 主角力量必须有明确成本 | 突破金丹→月供272%→灵脉要被抽 |
| 不能power creep | 每升一级，敌人也升一级→压力永远存在 |
| 规则博弈（不是武力博弈） | 陈默赢靠数字+规则漏洞+证据，不是靠灵气多 |
| 数字/符号贯穿 | 23331（共振+引爆）、8910（月供）、390万（贷款） |
| 锁链机制=全员绑定 | 所有人都欠房贷→谁都不能"掀桌" |
