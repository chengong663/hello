## 都市修真流派特殊规则

| 规则 | 说明 |
|---|---|
| 主角力量必须有明确成本 | 突破金丹→月供272%；引爆灵脉→灵脉掉1% |
| 不能power creep | 每次赢敌人→敌人就升级（秦广→陆坚→林七→萧云） |
| 规则博弈（不是武力博弈） | 陈默赢靠数字+规则漏洞+证据+让敌人自己"不想打" |
| 数字/符号贯穿 | 23331、8910、390万、2亿、37条灵脉 |
| 锁链机制=全员绑定 | 所有人都欠房贷→谁都不能"掀桌"→连反派都是棋子 |
| 每次Band 4/5必须有**明确成本** | Band 4炸林七→灵脉掉1%；Band 5炸林七（第二次）→灵脉再掉1% |
