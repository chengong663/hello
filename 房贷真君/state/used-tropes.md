## 都市修真流派特殊规则

| 规则 | 说明 |
|---|---|
| 主角力量必须有明确成本 | 突破金丹→月供272%；引爆灵脉→掉1%；炸灵气守卫→灵脉掉X% |
| 不能power creep | 每次赢敌人→敌人就升级（秦广→陆坚→林七→萧云→仙界银行上面） |
| 规则博弈（不是武力博弈） | 陈默赢靠：①规则漏洞（旧计算器检测不到）②数字游戏（成功率31%→95%）③让敌人自己不想打（萧云也是棋子）④让对手帮自己（大牙挖洞→完美不在场） |
| 数字/符号贯穿 | 23331、8910、2亿、37条、7个、3年、延后一年 |
| 锁链机制=全员绑定 | 所有人都有房贷→谁都不能"掀桌"→连反派都是棋子 |
| 完美不在场证明很重要 | 灵气池"漏了"→灵脉"自己共振"→妖兽"挖洞" |
| 每次Band 4/5必须有明确成本 | Band 4炸林七→灵脉掉1%；Band 5联手→灵脉再掉1%；炸灵气守卫→灵脉掉X%；周明元婴碎了 |
