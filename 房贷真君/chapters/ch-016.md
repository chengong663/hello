# 第十六章 稳定了

陈默连着三天没睡够。

不是不想睡——是灵脉山的采集器在共振，双向接口的反方向通路在运行，灵气从仙界银行的灵气池里**持续、稳定、缓慢**地流回灵脉。灵气流经过他打坐留的根，像一条细小的暖流，从丹田往身体走——金丹期之后这个感觉更明显了，灵气不是"空的"，是"实在的"，像呼吸似的。

但旧计算器算出来的共振公式23331是**脉冲式**的。灵气流一阵一阵的——每次持续约三秒，间隔约七秒。三秒流进来，七秒停住，三秒流进来，七秒停住。

为什么？

老吴帮他盯着。

老吴这几天没回矿洞——他搬来了灵脉山下面的一个天然石洞，用石块堵上洞口，只留一条缝。他每天蹲在采集器旁边，往石头里输灵气，记录灵气进出场的时间。

"三秒、七秒。"老吴的声音从洞口传进来，"我输了一万点灵气试了三次。每次都是三秒脉冲、七秒间隔。"

陈默的旧计算器亮着。屏幕上堆着一堆数字——灵气流速、脉冲频率、间隔长度。

23331 × 7 = 163317？不对。

3秒脉冲 + 7秒间隔 = 10秒一个循环。一天8640秒。一天864个循环。每个循环灵气流量——

他重新算。每个循环的灵气流量是**0.01%灵脉总浓度**。一天864个循环就是**8.64%**。

**但灵脉还在被采集器抽走。**

灵脉浓度每天净涨=反向流入8.64% - 被抽走约0.96%（采集器的固定消耗）= **7.68%/天**。

7.68%。

陈默的手指停了。如果保持这个速度，灵脉浓度从52.3%→100%需要 **(100-52.3)/7.68 ≈ 6.2 天**。

**六天。**

六天后灵脉就能恢复！

但他必须让共振**持续运行**——只要双向接口的反方向通路在工作，灵脉就在回升。如果共振断了，灵脉又会被采集器抽走。

"老吴。"陈默从山洞里出来，"你知道怎么让共振持续运行吗？"

老吴把采集器石头翻过来——背面的蓝纹在阳光下亮得很弱，有一处凹进去，像被什么东西烧过。

"不知道。"老吴摇头，"但我有个想法。"

他把采集器石头按在灵脉山的采集点上——两个石头又吸住了，蓝纹一起亮起来。

"23331是激活公式。激活之后，共振需要**持续的灵气供给**——就像烧火，你点燃了木柴，但如果不继续添柴，火就灭了。"

"你的意思是——"

"灵气供给不能断。"老吴指着陈默的丹田，"你的金丹期灵气量不够。但联合会有32个人。如果他们一起往灵脉里输灵气——"

32个人。金丹期只有陈默一个。剩下的都是筑基期甚至炼气期。

"筑基期的灵气输出大概是金丹期的1/10。"陈默在计算器上按了一下，"31个筑基期=3.1个金丹期。加上我1个=4.1个金丹期的总灵气输出。"

4.1个金丹期。够不够？

他算出了一个新公式。

灵气供给量=总人数 × 单人灵气输出 × 持续时间。需要的最小灵气供给量=23331脉冲的**维持消耗**——他之前测过，维持共振需要约500灵气/分钟。

32个人×每人每分钟15点（筑基期平均）= **480点/分钟**。

**差20点。**

"差20点。"陈默把旧计算器给老吴看，"32个人同时输灵气，还差20点/分钟才能维持共振。"

"那怎么办？"

陈默想了一下。"苏晚。"

苏晚是筑基后期，灵气输出比筑基期平均多25%——也就是18.75点/分钟。如果她也加入——

"480+3.75=483.75。还是差16.25。"

王老实呢？老吴呢？

老吴是炼气后期，但他有灵气匕首——匕首能把老吴的灵气放大1.5倍。老吴的输出是10×1.5=15点/分钟。

"483.75+15=498.75。"

**差1.25点。**

"差不多。"陈默按下等号，"可以试。"

他站起来，往茅屋方向走。路上他掏出旧计算器，把32个人的名字全部输进去，每个人后面标了灵气输出量——他把前几天联合会所有人的打坐效率和灵气量都测过一遍，精确到小数点后一位。

然后他在计算器里建了一个新的快捷程序——**灵气接力模式**。32个人分成8组，每组4人，轮流输灵气。每组输灵气1小时，然后下一组接上去。

这样就不需要所有人同时输——轮流来，每个人只需要输1小时/8小时=每天3小时就能覆盖全天。

**32人 → 8组 → 每组1小时接力 → 全天24小时灵气供给 → 维持共振 → 灵脉每天涨7.68% → 6天后恢复100%。**

陈默把旧计算器揣回口袋。

旧计算器在他手里很沉。屏幕上亮着32个名字和他们的灵气输出量。

他走到茅屋门口的时候，看到王老实从青石镇回来。

王老实这次带回了三箱干粮和一个消息——青石镇42个逾期者，全部愿意过来。

"他们说秦广调走了，新的还没来。"王老实把干粮放在地上，"还有绿水镇的刘大壮，我在路上碰到他了。他说等你这边确定了，他带绿水镇所有人过来。"

陈默的旧计算器又按了几下。

32+42=74。74+绿水镇约300人=**374人**。

374人的灵气接力。

他按下等号。屏幕显示：**灵气供给=5610点/分钟。共振维持消耗=500点/分钟。剩余=5110点/分钟。**

**足够。甚至溢出10倍。**

陈默抬头看了一眼灵脉山的方向。灵脉在阳光里亮了一点——浓度53.1%。

每天涨7.68%。6天后100%。

灵脉恢复。汇率回到1:200。390万灵气贷款。

**账开始往平了走了。**

他按下旧计算器上的"清零"键。然后又按了一串新数字——联合会374人的每日灵气消耗（维护+修炼+对抗）：

374人×每人12点/天（平均修炼消耗）= **4488点/天**。

双向接口每天流入的净灵气量：灵脉每天涨7.68%×1000万灵脉总量×汇率1:200（暂时算回到这个数）= 38400点/天。

**38400-4488=33912点/天净盈余。**

够还金丹期月供8910点+利息214点，还能剩2万多。

**账平了。**

陈默把旧计算器揣回口袋。他往王老实的肩膀上拍了一下。

"通知所有人。明天开始灵气接力。老吴负责盯采集器。苏晚负责记数字。"

"好。"

陈默转身往灵脉山走。阳光在他背上投下一个很短的影子——下午了。

他在灵脉山脚下碰到了苏晚。苏晚手里攥着账本，在等他。

"我把所有32个人的灵气输出量都测了。"苏晚把账本翻给他看，"和你计算器里的数字几乎完全一致。误差在±0.3%以内。"

陈默盯着账本上的数字。苏晚的账本比他的旧计算器更详细——每个人的灵气输出量、维持时间、消耗速度，都用碳笔写得密密麻麻，旁边还画了灵气输出的波动图。

"苏晚。"陈默说。

"嗯？"

"你算一下——如果陆坚来了。他会怎么对付我们？"

苏晚把账本翻到新的一页。碳笔在上面划了几条线。

"元婴中期的灵气量是金丹期的——"她停了一下，"约50倍。他一个人能打50个我。你金丹期，他能打你10个。"

"那我们374人呢？"

"374个里面只有你一个金丹期。其他都是筑基期以下。加起来约3个金丹期的总灵气量。"苏晚的碳笔在"3个"下面划了两道线，"陆坚50倍。你3倍。差16倍。"

16倍。

陈默的手指在旧计算器上按了几下。16倍的差距。灵气地雷1000点炸茅屋，800点炸采集器节点。陆坚元婴中期的灵气护盾约20000点。

**20个1000点灵气地雷同时爆，才能炸穿他的护盾。**

"但灵气地雷不是主要武器。"苏晚说，"秦广那次失败，是因为他自己也欠房贷——他不敢真的杀我们，因为杀了我们，他的月供也还不上。陆坚呢？"

陆坚的房贷情况。没人知道。

秦广被调走了。新的信贷主管陆坚。他有没有房贷？他的月供是多少？他会不会也被逼？

如果陆坚也欠房贷——那他也是锁链上的一环。如果他不欠——那他可能是天衡的人，甚至是仙界银行的人。

**两种可能，两种结局。**

陈默把旧计算器揣回口袋。

"苏晚，算一下陆坚两种情况的概率。"

苏晚低头在账本上画了几笔。"假设陆坚是天衡地产的职业经理人，他的月供概率是——"她写了一个数字，"85%。因为秦广也是。仙界银行的信贷主管直接绑定房贷，不欠房贷的人不能做这个职位。"

85%。陆坚欠房贷。

"那他也会被逼。"陈默说。

"但他比秦广狠。"苏晚的声音很轻，"秦广是被逼到临界点。陆坚可能还没到。"

还没到临界点。所以他敢动手。

陈默抬头看灵脉山的方向。灵脉山在阳光下闪着蓝光——53.1%。

6天后灵脉恢复。374人联合会。双向接口稳定运行。

但陆坚明天到。

**时间差。**

陈默的旧计算器按了一下。灵脉恢复还有6天。陆坚明天到。他有5天的时间差来做准备。

5天。

灵脉能涨到多少？53.1% + 5×7.68% = **91.5%**。

还没完全恢复。但已经接近了。

"苏晚。"陈默转身往山下走，"今晚开会。所有人。说一下灵气接力和陆坚的事。"

"好。"

风从灵脉山的方向吹过来，带着灵气。灵气在呼吸似的，一波一波的，很稳。

陈默掏出旧计算器，按了三下。

屏幕上显示：**灵脉53.1%。6天→100%。陆坚明天到。概率85%欠房贷。灵气地雷20个=炸穿护盾。374人=3倍金丹期。**

然后他按了等号。

屏幕显示：**暂无数据。**

他按了清除。然后又按了一串新数字。

算陆坚的月供。假设他元婴中期，月供是秦广的5倍——89100×5= **445500点/月**。

44万。月供。

陈默攥紧旧计算器。

陆坚的月供是他的50倍。

锁链在陆坚脖子上更紧。
