# 第四十七章 主池里的东西

一个小时四十分钟后。

王磊传回了西北角守卫的核心坐标。（X:876, Y:402, Z:-100）。和前三个角一样的结构，一样的2秒窗口，一样的6小时旋转周期。

四个角。四个4200万灵气的人形凝聚体。

王磊飘到了B3层的正中心上空。

然后他停了。

旧计算器屏幕上跳出一个亮斑。比四个角加起来还亮。不是人形——没有固定形状，像一团翻滚的星云，中心的密度能把王磊的白光挤开。

**正中心的守卫找到了。**

| 项目 | 数值 |
|---|---|
| 灵气密度 | 420,000,000 |
| 结构 | 灵气凝聚体·无固定形态·核心——未知 |
| 活动模式 | 不规则旋转·周期不稳定·随机3-9小时 |
| 感知范围 | 以它为圆心·80丈内有灵气波动则触发攻击 |

4.2亿灵气。

比四个角的守卫加起来还多——四个角总共才1.68亿，这一个是它们的2.5倍。而且它在正中心，在灵气池上面，在所有东西的中间。

"这——"苏晚的声音在发抖。"这不是灵气守卫。"

"对。"萧云的声音也变了。"我之前设计飞升管道的时候没有这个东西。它——"

"它是什么时候出现的。"陈默问。

"三个月前。"王老实从旁边走过来。手里攥着一枚刚偷到的印章。"我偷萧云的密信的时候，看到天衡城内部的灵气监测数据。三个月前——就是炸灵气池的那天——这个东西突然出现了。从主灵气池里冒出来的。"

从主灵气池里冒出来的。

因为他们偷了灵气池。炸了飞升管道。所以主灵气池里生出了这个东西。像身体里长了个异物，因为某个器官被捅了个窟窿。

陈默盯着旧计算器上的数字。4.2亿灵气。无固定形态。核心未知。感知范围80丈。

他按旧计算器：**三重爆炸公式能打多少？**

旧计算器算：990万×3（三次叠加）=2970万。加上灵脉共振的加成——2970万×1.8=5346万。加上双重汇聚——5346万×1.5=8019万。

8019万。对4.2亿。

19%。不够。差了五倍。而且这是在正中心，在灵气最浓的地方，它的感知范围有80丈——比四个角的20丈大了四倍。还没等你把爆炸引过去，它可能就先动了。

"萧云。"陈默转头。"你刚才要说的主池的事。"

萧云沉默了两秒。然后他开口。

"主灵气池不是天然形成的。"他看着灵脉入口的蓝光，声音平得像在念一份说明书。"是我设计飞升管道的时候一起建的。本来是灵气循环的中枢——37条灵脉的灵气汇聚到主池，再通过飞升管道输送给化神期以上的修士用。"

"然后呢。"

"然后有一天——大概是我穿越过来第三年——主池的灵气开始自己涨。我没往里充灵气，它自己涨。涨了17倍。"萧云的嘴角动了一下，"然后我查了一下——发现灵脉里的灵气在被某种东西从飞升管道里抽回来。不是飞升管道抽的。是飞升管道**里面**抽的。"

"里面是什么。"

"我没进去过。"萧云说。"但我设计飞升管道的时候留了一个后门——用23331的频率共振，管道会裂开一条缝。三个月前青阳城的飞升管道就是这么裂的。"

"你留了后门。"

"对。后门的激活码是23331。但打开需要——"萧云顿了一下，"和主池灵气总量一样多的23331频率的灵气。"

"多少。"

"我不知道。但三个月前我偷青阳城灵气池的时候测过主池的漏量——每天漏170万点。如果灵脉自身循环是正常的，那主池的总量应该在——"

苏晚的碳笔停了。她翻账本第37页——那里记着灵脉循环的灵气收支。

"170万/天。如果漏量是总灵气的0.01%——"她快速计算。"170亿。"

170亿灵气。

陈默的灵气余额是42000。170亿是他的40476倍。

旧计算器在他手里震动了一下——王磊传来新的灵气信号：正中心的那个东西转了一下。核心闪了一下。旧计算器记录下它的旋转周期——这一次是4小时21分钟。下次是随机。

"如果激活后门。"陈默说。"主灵气池会怎么样。"

"主池裂。飞升管道裂开一条缝。主灵气池的灵气会泄到灵脉里。37条灵脉同时涨。"萧云说，"涨多少？主池170亿灵气，37条灵脉平均分——每条涨4.59亿。"

青阳城灵脉现在的总量是多少？苏晚翻账本——"5800万。"

4.59亿是5800万的7.9倍。

"灵脉炸吗。"陈默问。

"不炸。"萧云说。"灵脉是天然灵气通道。涨了只会扩宽——最多涨到原来的10倍。灵气浓度从现在的12000涨到近十万。"

近十万。修士在这种浓度下打坐——修炼速度是现在的7.9倍。

但主灵气池里那个4.2亿的东西呢？

"主池裂了，它就没了。"萧云说，"它是主池灵气凝聚的。主池裂了——它失去灵气来源，会散。"

没了。

陈默盯着旧计算器上的数字。五个角的守卫能靠11秒窗口+三重爆炸打掉。正中心这个——直接让它的灵气来源消失。

但激活后门需要170亿23331频率的灵气。

他只有42000。

等等。

他按旧计算器：**23331共振是什么？**

旧计算器不算。但他知道——灵脉共振需要的不是"灵气总量"。是"频率匹配的灵气"。旧计算器能检测到23331频率的灵气。灵气石里有。灵脉里有。王磊的灵气是23331。旧计算器本身就是23331。

**需要的不是170亿灵气。是170亿点23331频率的灵气。**

现在灵脉里有多少23331频率的灵气？苏晚翻账本——"灵脉总灵气5800万。23331频率占37%——2146万。"

还差168亿。

但——如果37条灵脉同时共振呢？每条灵脉的23331灵气加起来——

他按旧计算器：**37条灵脉×青阳城2146万=79402万≈8亿。**

8亿。还是差90亿。

"有没有办法让灵脉自己共振。"陈默问萧云。

萧云想了想。"有。灵脉的共振频率是23331。如果旧计算器能同时在37条灵脉的每个节点发送23331信号——灵脉会自己共振。灵气会汇聚。但——"

"但什么。"

"但旧计算器只有一台。"萧云说。"除非——"

他没说完。但他和陈默同时看向了王磊。

王磊在灵脉里飘。灵气震动——23331——在灵脉网络里扩散。

王磊能走灵脉网络的每一条支路。能连接37个节点。能传递23331的信号。

**王磊+旧计算器+灵脉网络=37条灵脉同时共振。**

陈默按旧计算器。屏幕显示：

> 王磊走灵脉网络→连接37节点→旧计算器同步发送23331→灵脉同时共振→灵气汇聚→激活后门→主池裂→4.2亿守卫消失→灵气泄→灵脉涨8倍→飞升管道裂开。

成功率：**41%。**

比之前的78%低了。但比三个月前炸灵气池的31%高。

而且这次——目标不是炸控制中心。是**掀翻整个飞升系统**。

陈默把旧计算器揣回口袋。

"收工。"他说。"回去算账。"

苏晚合上账本。碳笔的笔尖又秃了。

王老实把印章揣回怀里。

萧云看了一眼灵脉深处。王磊的白光已经飘回来了。

陈默转身往回走。灵气石在口袋里沉甸甸的。

他掏出旧计算器，加了一行：

> 卷二·终极目标：37条灵脉共振→激活后门→掀翻飞升系统。

然后按清除。

穿越第一百八十一天的傍晚。灵脉入口的火在烧。灵气接力的人还在练——0.64秒误差。王磊的白光飘回灵脉深处。萧云化成一道光消失了。王老实蹲在旁边啃灵石头。苏晚在账本上记着新数字。

一切都在变。

从"活下去"到"掀翻系统"。

从被动的棋子到主动下棋的人。

从一个人的战斗到37条灵脉的共振。

陈默走进茅屋。灵脉野菜炒妖兽蛋已经摆在桌上。

苏晚坐下来。碳笔放在账本上。

"先吃饭。"她说。

"好。"

他拿起筷子。

月供还是8910。

但他有底牌了。
