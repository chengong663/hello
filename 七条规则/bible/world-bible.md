## 一、核心冲突源

一座城市被"规则"入侵——每天早上 7:07，所有居民收到一条短信，违反当日规则者死。规则发件人是"77777"，没人知道是谁在发。

**一句话概括**：每天一条神秘规则，违反即死。前刑警追查规则来源，发现和自己的家族有关。

## 二、物理规则层

### 2.1 规则机制
| 属性 | 说明 |
|---|---|
| 发布时间 | 每天 7:07（上午） |
| 发件人 | 77777（无法追踪） |
| 接收者 | 临海市所有手机用户，无一例外 |
| 规则内容 | 一句话，无解释，无容错 |
| 违规后果 | 100% 死亡，死亡方式与规则内容相关 |
| 死亡方式 | 与规则内容呼应（例："别碰红色"→红色物体致死） |
| 死亡感受 | 没有痛苦，是"释然感"——微笑着死 |

| 阶段 | 天数 | 规则特征 |
|---|---|---|
| 第一周 | 第1-6天 | 正常规则 |
| 第七天 | 第7天 | 大日子，死者全部微笑 |
| 第二周 | 第8-13天 | 可能与第一周规则呼应 |
| 第14天 | 大日子 | — |
| ... | ... | 七天一个循环 |
